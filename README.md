# Doctor Appointment Booking API

REST API built with Node.js, TypeScript, Express and MongoDB

## Tech Stack
- Node.js + TypeScript
- Express.js
- MongoDB + Mongoose
- JWT Authentication

## Features
- Role based auth (Patient, Admin)
- Doctor management
- Schedule & slot management
- Appointment booking with conflict detection
- Prescription management
- Reviews & auto rating calculation

## Setup
1. Clone repo
2. npm install
3. Create .env file (see .env.example)
4. npm run dev
